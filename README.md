# divination-skills

三个占卜技能，方法不一样：塔罗牌、梅花易数、手相。

共同的写法是把「怎么起」和「怎么解」分开。牌和卦由你来定，技能不替你抽；它负责查意义、按步骤推断，最后给能落地的建议。

## 三个技能

| 技能 | 触发 | 方法 |
|---|---|---|
| tarot | `$塔罗 [问题]`、抽牌、解牌、牌阵、每日一牌 | 三种选牌路径；78 张中文牌义 + 常用牌阵 |
| plum-blossom-divination | `$占卜 [主题] [参数...]` | 五种起卦：时辰占、数字占、物象占、一字占、多字占；断卦十步 |
| palm-reading | 先发手掌照片，再发【手相】 | 八维看相：手型七型、掌色掌质、掌丘八处、三大主线、辅助线、纹记符号、左右对比 |

## 塔罗的牌是你自己选的

三种路径都由你定牌，脚本不替你抽：

1. 直接报牌名和正逆位，`scripts/lookup.py` 查义，别名和错别字都能认。
2. 报编号盲抽：`scripts/deal.py --new` 先把 78 张真随机洗好、藏进状态文件，只显示位置表和你要报几个数字；报完再 `--reveal <state_id> --picks 12,45,7`。洗牌用 `secrets.SystemRandom()`，翻牌前从状态文件里读不到牌面。
3. 发牌面照片，按图认牌。

改牌义要改 `data/parts/` 下的三个分片，再跑 `scripts/build_data.py` 合并；直接改 `data/cards.json` 会被覆盖。改完数据或脚本跑一次 `scripts/precheck.py`，硬检查不过（退出码 2）就不许拿这份数据解读。

## 梅花易数的五种起卦

按你给的东西分派：

- 参数是纯数字 → 数字占，个数不定。
- 前一条消息带图，或给的是方位词 → 物象占。
- 什么参数都没有 → 时辰占（年月日时）。
- 给一个字 → 一字占：拆结构定上下卦，笔画方向分阴阳，笔画平分加时辰数取动爻。
- 给多个字 → 多字占：两个字按笔画，三个字以上按字数，停匀平分、不匀则上少下多。

断卦十步：卦辞助断、体用生克定吉凶（核心）、卦气旺衰修正、互卦看过程变卦看结局、从生体之卦细化吉事、按主题分类解读、应期、万物类象、克应、论理诀原则。

字占用的汉字结构、笔画数、笔画方向三张表在 `scripts/` 下，是现成的数据文件，不用自己准备。

## 手相

先发照片再发【手相】触发：默认第一张是左手、之后的是右手。八篇参考按手型、掌色、掌丘、主线、辅助线、纹记、左右分别整理，分析时按这八维过一遍。

## 安装

把 `skills/` 下的三个目录复制进技能根目录：

```
~/.dsh/skills/        # DSH
~/.claude/skills/     # Claude Code
```

## 依赖

塔罗的脚本只用 Python 标准库。梅花易数的起卦脚本是 Node（`node scripts/divination.cjs <主题> [参数...]`），农历库已经放在 `scripts/vendor/` 里，不需要 npm install。手相只用 Markdown 参考。
