# 掌色与掌质（《手相学大全》第四章）

手的颜色、大小、软硬及其他，补充观察整个手质。

## 掌色（重点）

| 掌色 | 论断 |
|:---|:---|
| 粉红 | 健康良好，性情乐观，福至心灵 |
| 特红如朱砂 | 体魄强壮、血液充沛，但性情刚烈，易走极端而难以自制；并有患肠胃病的倾向 |
| 黄明 | 活泼敏捷，生气勃勃，福至心灵 |
| 黄暗 | 抑郁寡欢，性带傲慢；并可能有肝藏（肝脏）病 |
| 青暗 | 神经过敏，心膻（胆）怯弱 |
| 蓝紫 | 血液循环不良，心脏可能有毛病，做事每多窒碍 |
| 白而毫无血色 | 寡情薄义，利己心重，傲慢自大而毫不谅人 |

## 掌质（软硬厚薄）

| 掌质 | 论断 |
|:---|:---|
| 掌厚而软，指又丰盈 | 情欲炽盛，易沉迷于酒色 |
| 掌硬而薄，皮肤枯燥 | 性懦，忧郁，神经过敏 |
| 掌软而不厚，皮肉松弛 | 好奢侈，慕虚荣 |
| 手掌特殊柔软 | 感情易冲动，喜怒形于色，但心地甚慈 |
| 骨硬、肉实、气浊、形杂 | 劳而无功，命途多舛 |
| 不论行坐，手常紧握 | 有决断力，但自私心亦重 |
| 行路时手软垂无力如挂尸 | 懒惰成性 |
| 手常感到冷湿 | 健康不甚良好，神经有过敏倾向 |

## 手背毛

| 手背毛况 | 论断 |
|:---|:---|
| 手背粗而多毛 | 体魄强壮，但性格粗卤 |
| 多毛而手背不粗 | 爱奢华，慕虚荣 |
| 手背毛少而幼细 | 多为温文尔雅之辈 |
| 妇女之手随处生毛 | 性多残忍 |

## 手的大小（本书第四章涉及）

- 手大的人：能注意精细工作（相参照系：以身体比例论）
- 手小的人：反不喜欢精细工作，好高骛远，往往有出人意表的行动；若为妇女，更易受刺激及激动

## 判断要点
1. 掌色需在自然光下观察，照片色差大时说明"照片环境下掌色判断有限"
2. 软硬厚薄照片无法完全判断时，说明该局限，仅就可见部分（如骨节、丰瘦）论断
