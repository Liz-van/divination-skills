# 纹记符号（《手相学大全》第八章/第十一章）

## 基础纹记（第八章：线条上的符号）

| 符号 | 形态 | 一般论断 |
|:---|:---|:---|
| 岛形 | 线上一小岛状 | 主该线所主领域有波折、阻碍、疾病（如生命线岛形主病，感情线岛形主情伤，命运线岛形主事业困顿） |
| 斑点 | 线上的点 | 主该处所主之事有凶险/疾病（如生命线斑点主疾病，婚姻线斑点主婚姻打击） |
| 十字 | 交叉线 | 主变化、阻碍，按所在部位定吉凶（详见下） |
| 花星 | 放射状星形 | 主成就、名声、意外之喜，按所在部位定（详见下） |
| 网形（格子形） | 网格状 | 主困扰、阻滞，多为凶象（详见下） |
| 三角形 | 三角状 | 主才能、吉象（详见下） |
| 叉形（义锋） | 线端分叉 | 抬头向上的主吉（上升叉），向下垂的主凶 |
| 链状（锁链形） | 线如链条 | 主该线所主领域波折、不稳定 |
| 圆环 | 环状 | 在太阳丘主前途光明，在太阴丘主水厄（水险），其余多为破坏作用 |
| 方形（方格） | 方块状 | 保护记号：该处原有的凶象受保护、化险为夷；方形破缺则保护作用减弱 |
| 丛毛线 | 状如翘毛 | 为不吉之兆（该线所主领域多烦恼） |
| 毛状线 | 主纹两旁同时岔出的短线 | 主该线力量分散、受干扰 |
| 不测线 | 头大尾小 | 主凶（意外、突变） |

## 符号按部位定吉凶（第十一章）

### 十字
| 部位 | 论断 |
|:---|:---|
| 木星丘 | 主有美满姻缘，结婚年龄约二十八至三十岁之间 |
| 食指基部 | 主晚婚；一说主目的可达、野心满足 |
| 接近理智线 | 主早婚，同时亦主性格果断、百折不挠 |
| 太阳丘 | 主名誉地位皆有损失 |
| 土星丘（一说） | 为失败之徵；又一说主（人生）结局的艰难困苦 |

### 花星
| 部位 | 论断 |
|:---|:---|
| 木星丘 | 主有领袖才能，权力在握，声名显赫；一说主其人之计划（成功） |
| 土星丘 | 主有声名，但性属冒险，难免死於非命；一说主有遭人暗（算）之险 |
| 太阳丘 | 主获得财富与名誉，但缺乏幸福；一说事业虽告成功，但心不知足，因而无幸福可言 |
| 水星丘 | 主在科学上的事业有所成就，或因雄辩而得令名；一说：男性主有凶险，女性主能著述且名利兼收 |
| 第一火星丘 | 主得军事上的令名（武职/竞技成就） |
| 第二火星丘 | 主能忍辱负重，卒享大名（如越王勾践之终能报仇） |
| 金星丘 | 主命带桃花，所幸多数成功 |
| 金星丘底部而稍侧 | 主与显贵之人相恋 |
| 金星丘的拇指基部 | 主有军事上的特殊才能，战无不胜 |
| 太阴丘 | 主想像与创造力强，事业有成 |
| 感情与理智线之间（掌心） | 主其人坚毅果敢，能克服一切困难终成大业；或主其人有伟大的发明天才 |
| 各指顶部 | 主其人触觉特别敏锐，能以手指代替眼睛 |
| 小指顶部 | 主其人口若悬河，听者动容 |

### 网形（格子）
| 部位 | 论断 |
|:---|:---|
| 木星丘 | 主其人自高自大 |
| 土星丘 | 主其人命途多舛；一说主忧郁心重 |
| 太阳丘 | 主慕虚荣 |
| 水星丘 | 主浮躁不实 |
| 第一火星丘 | 主易招凶死 |

| 太阴丘 | 主处事不沉着，心常沮丧；或因过度妄想而生忧郁 |
| 掌中央 | 主有杀人倾向（现代转化：情绪极端、有攻击性倾向，须结合整体判断，不可轻断） |

### 三角形
| 部位 | 论断 |
|:---|:---|
| 水星丘 | 主有经商之才 |
| 第一火星丘 | 主有军事上的大才 |
| 第二火星丘 | 主长于军警事务，事事处理得当而态度镇定 |
| 金星丘 | 主能克己自制，不沉溺于爱河之中 |
| 太阴丘 | 主想像力强 |

## 判断要点
1. 符号须结合所在部位（丘/线）解读，同一符号在不同部位吉凶相反
2. 网形、十字等凶象论断（如"杀人倾向""横死"）为旧时夸张断语，现代解读须转化：转为情绪管理、行事风格、健康注意等现实表达
3. 方形为保护记号，出现时说明"凶象受制、有惊无险"
4. 照片中细小符号看不清时，如实说明，不强行编造
