# 三大主线（《手相学大全》第七章/第十章）

掌纹主要表现人的命运（过去的遭遇和未来的趋向）。三大主线为生命线、理智线、感情线，有些人连三大主线都不齐备——纹多纹少各有分别，须据实观察。

## 生命线（拇指侧、包绕金星丘的弧线）

**代表**：生命力、健康、体质；也关联寿命长短的观念（本书按东方人实际以不同年龄节点论流年）。

### 基本形态
- **明朗深长**：本主健康长寿；如更有内生命线在旁出现，则其人出生入死皆可履险如夷
- 内生命线岔出一线直趋太阴丘：人刚强急躁，并有沉溺酒色倾向
- 内生命线上出现花星：主其人能获得军功，并享有终身荣誉

### 常见纹变（按书中图注整理）
| 形态 | 论断 |
|:---|:---|
| 生命线中途见岛形或圆环 | 主疾病或健康受阻（岛形主病） |
| 生命线上起斑点 | 主当疾病；斑点明显处对应流年 |
| 生命线中途起钩 | 主凶险（原文"必死无疑"为旧时夸张断语，须结合时代性转化，只断"健康有重大波折"） |
| 生命线中途断裂 | 主健康有中断性危机，若另线从旁接续则主逢凶化吉 |
| 生命线为许多驳杂线条形成 | 体质弱、精力分散，健康欠佳 |
| 生命线上部出现多条细小横纹 | 主其（早年）多病或操劳 |
| 生命线上有许多小圈连成链形 | 主其人（健康）多波折，体质偏弱 |
| 生命线上出现方形 | 本为好事（方形为保护记号），但该方形若破缺则保护作用减弱 |
| 生命线有一支线上升至土星丘 | 主（通过努力）获得地位成就 |
| 生命线下部岔出之游历线（如末梢成叉） | 主远行、迁移之象 |
| 生命线起斑点点处 | 对应流年健康有疾 |

### 起点与理智线关系
- 生命线首端与理智线介乎（起点相连/靠近）：主谨慎保守，凡事三思
- 生命线首端与理智线分开较远：主性急、行动先于思考

## 理智线（头脑线，横过掌心）

**代表**：智力、思想方式、决断力、精神状况。

### 基本形态
- **向上翘起**：主其人聪明绝顶，坚决果断，虽不免神经过敏，然能自制，并不避事之艰难，勇往直前
- **分源而出（与生命线分开起点），其间相距不过阔的**：主其人聪明敏捷，思想自由，奋斗而有决断；一说性情易冲动、思想易变；但对于文学一途则比较荒疏
- **横过掌心而末端稍稍翘起**：主其人胆识高超，英明果断，能领导群众，处理国家大事；勇敢无畏，不惜牺牲家庭幸福以赴事功
- **理智线向下成叉形**（一端叉向下）：主其人过度小心，患得患失，常因小事与人交恶，遇有困难辄萌退志
- **从（生命线）内发出，通过掌心而翘起**：主其人能克服神经弱质，渐入佳境
- **从（生命线）内发出，倾斜而下直达太阴丘或掌颈**：主其人老而愈不实际，愈多不良嗜好
- **理智线满布纹如毛**：主思虑过度、神经衰弱、精神散乱
- **理智线上有清晰支线岔至（某丘）**：支线所向之丘的领域为其才能发挥方向（如岔至水星丘→经商口才；岔至太阳丘→艺术成名）
- **理智线与生命线（起点）相距关系**：起点分开大→独立自主性强、行动急；起点相连→谨慎依赖

## 感情线（小指侧起、横过上部的弧线）

**代表**：感情、情爱方式、婚姻态度。

### 基本形态
- **过长，由木星丘之掌边直达水星丘之掌边**：主热情而薄悻，妒忌心重
- **起自木星丘底部而首端弯下**：主其人滥施爱情，但心（地不专/易变）
- **特长、深而笔直**：主其人冷酷无情；若手形又复恶劣，则（旧断语"杀人放火"）须结合时代性转化——断其感情冷漠、缺乏同情、极端时行事偏激
- **在食指之下成叉状**：主感情生活有分支/抉择，或主两段感情经历
- **感情线被多条细纹穿过**：主感情多波折、易受外界干扰
- **感情线有多数细纹下垂**：主（感情上）易失望、多愁善感
- **感情线上出现岛形**：主其人（感情）有波折、失恋或婚恋不顺之象
- **感情线上出现斑点或圆环**：主感情上有重大打击或伤心事
- **感情线不清晰又有细纹重叠而行**：主感情生活混乱、思绪不宁
- **感情线断续连叠如梯状**：主感情多变、难稳定
- **感情线起自第一火星丘内**：主感情热烈而急躁
- **感情线在食指之下（木星丘）成叉状**：主所爱之人（形象）……，感情上有理想化倾向

## 三大主线综合判断要点
1. **深浅**：线深而清→该项特质明显；线浅而淡→特质弱或潜力未发
2. **长短**：以是否横过掌心、到达哪个丘为判断基准
3. **断裂/续接**：断而有线接续→波折后恢复；断而无接→中断性变化
4. 三大主线互参：生命线好但理智线满布小岛而下垂、命运线有十字——则整体判断（如健康虽好但精神/事业有困扰），**不可执一以断**
