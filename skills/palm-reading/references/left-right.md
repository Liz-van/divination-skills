# 左右手与综合论断（《手相学大全》)

## 手形各部分相互印象（第六章）

- **拇指代表个性及特种能力**，四指代表智愚敏拙和工作方法，指甲代表健康，掌丘代表各种性能的强弱
- **主从关系**：拇指是主，四指是从。四指之优敌不过一指之劣——拇指有缺陷，四指再好也难成功
- 若无主从关系的地方则不作此观：如食指优而其余三指劣，则食指所代表的野心（特质）突出，其余弱化
- 掌纹与手形互相牵结影响：掌纹好而手形不佳，或反之，都要综合看，不可偏废

## 理智感情线距离广狭（第十二章）

理智线与感情线距离的广狭，以及感情线距指根基部的远近，决定其人意识的内向或外向、对人同情心的大小：

- **理智线和感情线相距甚窄**：其人必多为自身谋划（自我中心、精于算计），纵有时能表现为利他……但根本上为自己打算；对人事务实而忠诚
- **感情线距指基近**：对人缺乏同情心
- **感情线距指基远**：富于同情心
- 两线距离宽 → 内向深沉、思虑多；距离窄 → 外向务实、自我

## 左右手问题

**默认规则（不做图像左右判断）**：用户先发左手、后发右手——**先发的照片 = 左手，后发的 = 右手**。多张照片按发送顺序依次分配；同一只手可有多张。用户明确说明左右时以用户说法为准。

- **左手 = 先天**：禀赋、潜质、幼年环境、与生俱来的倾向
- **右手 = 后天**：现实、努力、现状与发展、人生实际的轨迹
- **论断原则**：
  - 以**右手为主**断当前状况与未来趋向（右手是后天努力的结果）
  - **左右对比**看变化：右手线优于左手 → 后天努力改善了先天；右手线差于左手 → 先天禀赋未被善用或后天损耗

## 线的流年（本书：东方人体系）

- 本书流年图按**东方人的实际**情况制作（西方人多以九十岁为终点，作者经验颇不适用于中国）
- 生命线流年：从拇指侧起点（幼年）沿弧线向下至腕部（晚年）
- 理智线流年：从起点向末端推进
- 感情线流年：从小指侧向食指侧推进
- 命运线流年：从掌颈向土星丘推进
- 断应期时给大概年龄区间，不精确到年份

## 综合论断原则（本书第十四/十五章）

1. **不可执一以断**：掌上各种线条尽管各有含义，但不是孤立的，各线之间息息相关、互为生克。假如执一以断，即不根本错误，亦必难有是处
   - 例：生命线良好、丝毫看不出凶险或多病迹象，但理智线漫布小岛而下垂、命运线上出现十字 → 整体论断应为"健康底子尚可，但精神/事业有困扰"
2. **手形掌纹并重**：手形主要表现人的品格，掌纹主要表现人的命运；两者不可偏废，偏废即不足以言手相
3. **结合时代环境**：手相与时代环境关系极重要。墨守成规、不知时移世变、以古人之术硬断今人休咎，必然出错。旧断语（高官厚爵、杀人放火、横死等）必须转化为现代语境的现实表达
4. **成功多元**：人的成功是多方面的。发志图强是成功之一，但学业有成、修养有德、能造福人群社会，尽管穷极困极，又何尝不是大大的成功
5. **变通处靠意会**：相生相克处、色彩转换、纹理气势变化等，常非言语可以解释，须凭意会和经验得来——解读时注意整体气势与协调性

## 报告维度（第八章末尾建议）

综合论断按五个维度组织，每个维度给出"当前状态 + 需要注意/可发展的方向"：
- **性格**：手型 + 理智线 + 掌丘为主
- **健康**：生命线 + 健康线 + 掌色为主
- **事业**：命运线 + 成功线 + 木星丘/太阳丘为主
- **感情**：感情线 + 婚姻线 + 金星丘/影响线为主
- **财运**：太阳丘 + 水星丘 + 命运线支线为主

**语气要求**：各维度给出具体观察依据与对应解读，不确定处（照片不清、纹路模糊）如实说明；凶象用"注意、宜防、需调适"等现实化表达，不渲染恐怖，也不强行扭向积极。
