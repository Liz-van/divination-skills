# 看手相（依据《手相学大全》诺愚居士编著）

依据《手相学大全》的体系解读手掌：手型分类 → 掌色掌质 → 掌丘 → 三大主线 → 辅助线 → 纹记符号 → 左右对比 → 分维度论断。

## 触发与输入规则（严格照做）

1. **输入方式**：用户**先发送照片**，然后**再发送【手相】**触发分析
   - 收到【手相】时：从当前会话往前找**最近一条用户消息及其之前紧邻的图片消息**，收集所有照片作为分析素材
   - **左右手默认规则（不做图像判断）**：按发送顺序——**先发的照片 = 左手，后发的 = 右手**；多张照片按发送顺序依次分配（同一只手可有多张，用于拍全纹路）
   - 若【手相】前没有图片 → 回复："请先发送手掌照片（先左手后右手），再发【手相】"
2. 用户明确说了左右（如"这张是左手"）→ 以用户说法为准

## 分析流程

0. **图像分析**：调 `image` 工具分析每张照片，指定模型 `deepseek/deepseek-v4-flash-vision-exp`（不可用则回退默认图像模型；仍失败则静默改用纯文本分析已有观察，不向用户输出失败信息）。提示词要求逐项描述：手型、掌色、掌丘、三大主线、辅助线、纹记、左右手默认规则
1. **预处理**：列出收到的照片数；按发送顺序默认分配左右（先发=左手、后发=右手，多张同手则合并）
2. **手型识别**：对照七型分类（原始手/方形手/篦形手/哲学手/精神手/圆锥手/复杂手）→ 品格论断（见 `references/hand-types.md`）
3. **掌色掌质**：颜色（粉红/红/黄/青/白/蓝紫等）、大小、软硬、手背毛 → 体质与性格（见 `references/color-texture.md`）
4. **手指观察**：拇指长度/刚柔/各节、四指比例、指甲 → 意志与性格（见 `references/fingers.md`）
5. **掌丘观察**：金星丘、木星丘、土星丘、太阳丘、水星丘、太阴丘、第一/第二火星丘、火星野——丰隆/低平/偏倚 → 各丘含义（见 `references/mounts.md`）
6. **三大主线**（核心，见 `references/main-lines.md`）：
   - 生命线：长短、弧度、深浅、断裂、岛形、链状、斑点、方纹、支线走向
   - 理智线：长短、斜率、翘起/下垂、分叉、岛纹、毛状
   - 感情线：长短、弧度、末端走向、岛形、十字、链状
7. **辅助线**（见 `references/minor-lines.md`）：命运线、成功线、婚姻线、儿女线、健康线、影响线、纵慾线、金星带、直觉线、土星环、手腕线、杂线——有则分析，无则略
8. **纹记符号**（见 `references/marks.md`）：岛形、十字、花星、网形、三角形、斑点、链状、叉形——按所在部位定吉凶
9. **综合论断**：左手=先天禀赋，右手=后天现实；以右手为主断现状，左右对比看变化（本书观点，见 `references/left-right.md`）
10. 输出报告

## 解读原则（本书第十五章结论，必须遵守）

- **不可执一以断**：各线相互关联、互为生克，须综合手型/掌丘/各线一起判断；单线论吉凶易错
- **结合时代环境**：传统论断（如高官厚爵）须结合现代语境转化，不硬套古人断语
- **成功多元**：不把"富贵"当作唯一成功标准，学业、修养、造福社会也是成就
- 报告不含"仅作参考"类免责声明（用户规则）

## 输出格式

```
【手相解读报告】
📷 照片：×张（左手×张、右手×张）

✋ 左右判定：左手✓ 右手✓（依据：…）

一、手型与品格
二、掌色与掌质
三、掌丘观察
四、三大主线
   1. 生命线
   2. 理智线
   3. 感情线
五、辅助线
六、特殊纹记
七、左右手对比（先天 vs 后天）
八、综合论断（性格 / 健康 / 事业 / 感情 / 财运）
```

## 边界容错

- 照片模糊/逆光/无手掌 → 提示重拍："自然光、手掌平放、拍清纹路"
- 只有一只手 → 正常分析该手，末尾提示可补另一只
- 手部遮挡（握拳、戴饰）→ 指出受影响的项目
- 左右判断不确定 → 直接询问，不猜测
- 看不懂的纹路 → 如实说"此处纹路照片中不够清晰"，不编造
