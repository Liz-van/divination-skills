# 梅花易数占卜

依据梅花易数断卦体系完整断卦。

## 触发与输入规则

```
$占卜 <主题>                   → 无图则时辰占；前一条消息紧邻带图片则物象占（无方位）
$占卜 <主题> <数字...>         → 数字占（数字以空格分隔，个数不定）
$占卜 <主题> <方位>            → 物象占（前一条消息紧邻带图片，方位=拍照时面向的方向）
$占卜 <主题> <字>              → 一字占（结构拆解 / 笔画方向分阴阳 / 笔画平分+时辰数）
$占卜 <主题> <字串>            → 多字占（2字按笔画起卦；3字以上按字数起卦）
```

规则：
1. 「占卜」为命令前缀
2. **参数解析（执行时必须严格照做，禁止自拟主题、禁止漏传参数）**：
   - 将用户消息去掉「占卜」前缀后**按空格切分**：第一个字段 = 主题（爱情、考试、事业、出行、失物、健康、游戏对局……）
   - 之后的字段 = 参数，按以下**优先级**判定起卦方式：
     1. **参数全部为纯数字**（每个字段匹配 `^\d+$`，可多位）→ **数字占**，数字个数不定、按顺序使用
     2. **无参数** 且 **前一条用户消息含图片附件** → **物象占**（无方位）
     3. **无参数** 且 **前一条消息无图片** → **时辰占**
     4. **参数为方位词**（东/南/西/北/东南/东北/西南/西北）且 **前一条消息含图片** → **物象占**（该方位 = 拍照时面向的方向）
     5. 其余 → **字占**：多个参数直接拼接、**不加任何分隔符**（如 `$占卜 事业 一帆风顺` → 字串=`一帆风顺`）
   - 主题和参数必须**原样使用用户给的词**，不得替换成自己的说法
   - 示例：`占卜 这把三角洲全面战场 立` → 主题=`这把三角洲全面战场`，字=`立`（一字占）
   - 示例：`占卜 考试 3 7 9` → 主题=`考试`，数字=`3 7 9`（数字占）
   - 示例：图片 + `占卜 出行 南` → 主题=`出行`，方位=`南`（物象占）
3. 无参数且无图片 → 时辰占

## 计算脚本

```bash
node scripts/divination.cjs <主题> [字串]                                        # 时辰占 / 字占
node scripts/divination.cjs <主题> <数字1> [数字2] ...                           # 数字占（数字以空格分隔）
node scripts/divination.cjs <主题> --object <上卦名|数> <下卦名|数|方位> [动爻]  # 物象占
```
输出 JSON：本卦/互卦/变卦、体用生克、动爻、卦气旺衰、占时（含农历）。
若返回 error（单笔画字、无法识别的物象卦等），按提示改用时辰占。

⚠️ **传参检查（执行前必做）**：用户原句里有几个参数就传几个——用户给了字，原样拼接传入；用户给了数字，按空格分隔原样传入；物象占把归卦结果以 `--object <上卦> <下卦>` 传入（如 `divination.cjs "爱情" --object 离 东`）；只有用户确实没给参数时才可省略走时辰占。

## 数字占起卦规则

主题后参数全部为纯数字时按**数字占**（n = 数字个数，以空格分隔、个数不定）：

| 个数 | 上卦 | 下卦 | 动爻 |
|:---:|:---|:---|:---|
| n=1 | 数1 余8 | (数1 + 时辰数) 余8 | (数1 + 时辰数) 余6 |
| n=2 | 数1 余8 | 数2 余8 | (数1+数2+时辰数) 余6 |
| n≥3 | 前 ⌊n/2⌋ 个之和 余8 | 后 ⌈n/2⌉ 个之和 余8 | (总和+时辰数) 余6 |

余 0 作 8（卦）/ 作 6（动爻）。多位数（如 520、2333）视为一个数。

## 物象占

**触发**：「占卜」消息的**前一条用户消息含图片附件**，且：
- 主题后无参数 → 物象占（无方位）
- 主题后一个方位参数（东/南/西/北/东南/东北/西南/西北）→ 物象占（该方位 = 拍照时面向的方向）

**执行流程**（视觉模型只做看图，断卦主体仍是 deepseek v4 flash）：
1. 取前一条消息的图片路径
2. 调 `image` 工具并指定模型 `deepseek/deepseek-v4-flash-vision-exp` 分析图片，提示词：「描述这张图片中的主要物象、数量、颜色、场景；如有明显方位线索一并说明」。vision-exp 不可用则回退默认图像模型；仍失败则静默改用时辰占，不向用户输出失败信息
3. 按⑧万物类象简表把**主物象**归为**上卦**（如：马→乾、牛→坤、鸡→巽、雉龟→离、猪鱼→坎、虎狗→艮、羊→兑、龙蛇→震、金玉圆物→乾、竹木→震、文书火→离、水酒器→坎、土石瓜果→艮、金刀乐器→兑、布帛方物→坤）
4. **下卦**取法（优先级从高到低）：
   - 用户给了方位参数 → 方位归卦：东震 / 南离 / 西兑 / 北坎 / 东南巽 / 东北艮 / 西南坤 / 西北乾
   - 无方位 → 画面中的**次要物象**之卦
   - 再无 → 主物象**数量** 余8
5. 动爻 = (上卦数 + 下卦数 + 时辰数) 余6（脚本自动算，也可显式传第4个参数）
6. 调脚本：`node scripts/divination.cjs <主题> --object <上卦> <下卦> [动爻]`
7. 按断卦流程完整解读，解读时说明取象依据（主物象为何卦、下卦取自方位/次物象/数量）

## 断卦流程

按以下顺序解读，全部综合后给出结论：

### ① 卦辞助断
引用脚本输出的本卦卦辞（`original_hexagram.judgment`），可结合动爻位置（初爻~上爻）提示当前关键所在。

### ② 体用生克断吉凶（核心）
体卦为己、为所占之人事之主；用卦为所问之事。**含动爻者为用卦，不含者为体卦**（脚本已算好）。

| 关系 | 吉凶 | 含义 |
|:----:|:----:|:----|
| 用生体 | **大吉** | 外力相助，得贵人扶助，事半功倍 |
| 比和 | **大吉** | 体用同五行，和谐一致，诸事顺遂 |
| 体克用 | **中吉** | 我能掌控局面，事可成，但需努力、见效较慢 |
| 体生用 | **小凶** | 我生者为泄气，耗损自身，谋事多费周折 |
| 用克体 | **凶** | 外力克制于我，所谋难成，宜守不宜攻 |

**措辞要求**：小凶只陈述「耗损、费周折」，不得加「但终有回报」类保证；凶只说「难成、宜守」，给出守/待时/转向的具体方向即可，不包装成积极结局。

### ③ 卦气旺衰修正
按**农历月**判断体卦五行旺衰（脚本 `gua_qi` 已输出）：
- 春（寅卯辰月）木旺、土衰；夏（巳午未月）火旺、金衰
- 秋（申酉戌月）金旺、木衰；冬（亥子丑月）水旺、火衰
- 四季月（辰戌丑未）土旺、水衰

体旺 → 吉则增吉、凶可缓；体衰 → 吉打折扣、凶则更凶。解读时说明旺衰对结论的影响。

### ④ 互卦=过程，变卦=结局
- 互卦（脚本 `hu_hexagram`）表示事物发展**中间阶段**出现的人或事
- 变卦（脚本 `changed_hexagram`）表示**最终阶段**与结局
- 用吉而变凶 → 先吉后凶；用凶而变吉 → 先凶后吉
- 体卦同类多则体势旺，用卦同类多则体势衰

将主题映射到分类条目，用**体用五关系**给出针对性结论：

### ⑨ 克应
提示求占者：起卦前后注意身边外应——听到吉利/凶恶话语、见圆物易成、见残缺物不顺，可并入卦断综合判断。

### ⑩ 论理诀原则
- 义理象数结合：卦象须合常理（如冬占震卦不应断雷，应断狂风）
- 不机械套模板：个别情况（如寺庙纯阳之地占得阴卦多）可据理直断，不必拘执体用
- 圆融变通，最忌胶柱鼓瑟

## 输出格式

按以下结构输出解读（结合主题，语言自然，不照搬脚本字段）：

1. **起卦**：说明本次起卦方式与占时（含农历、时辰）
2. **得卦**：本卦名（卦辞）、动爻、互卦、变卦
3. **体用**：体卦（五行、旺衰）、用卦（五行），生克关系与吉凶
4. **过程与结局**：互卦预示的过程、变卦预示的结局
5. **分类结论**：结合主题，按分类条目的五关系结论给出
6. **应期**（尽量给）：按卦气给出时间参考
7. **建议**：大吉/中吉顺势给出积极建议；小凶说明耗损之处；凶给出守/待时/转向的具体方向——**不强行扭向积极**
