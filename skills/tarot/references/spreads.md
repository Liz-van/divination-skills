# 牌阵与位置含义

## 推荐规则

| 场景 | 牌阵 | 张数 |
| --- | --- | --- |
| 每日指引 / 简单问题 | `single` 单张 | 1 |
| 一般问题 / 是或否 / 没指定 | `three` 三张（过去-现在-未来） | 3 |
| 二选一决策 | `choice` 选A-选B-建议 | 3 |
| 关系 / 感情 | `relation` 关系牌阵 | 5 |
| 卡住的决策 | `diamond` 五牌 | 5 |
| 一个月周期 | `moon` 月相牌阵 | 4 |
| 时间线推演 | `horseshoe` 马蹄形 | 7 |
| 局面复杂 / 要深挖 | `celtic` 凯尔特十字 | 10 |

用户指定了牌阵就用用户的，不要劝他改。位置名和顺序一律用下表的，不要临时另起一套。

## 位置定义

**single 单张**
1. 当前指引——这件事此刻最需要你看见的是什么。

**three 三张**
1. 过去——已经发生、正在影响你的那件事（不是宿命，是背景）。
2. 现在——你此刻的真实处境。
3. 未来——按现在的走法，事情会往哪去（可改，取决于选择）。
变体：`你/对方/关系` 或 `情况/行动/结果`——用户要求时按变体命名位置。

**choice 二选一**
1. 选 A 会怎样。
2. 选 B 会怎样。
3. 建议——帮你选的那把尺子是什么。

**relation 关系（5 张）**
1. 你现在的状态。
2. 对方现在的状态。
3. 你们之间的连接——现在真正连着的是什么。
4. 卡点——反复出现的那个结。
5. 走向 / 建议。

**diamond 五牌**
1. 核心——问题真正的中心。
2. 根源——它从哪来。
3. 阻力——拦着你的是什么（外部的或你自己的）。
4. 潜力——还没被用上的资源。
5. 建议——下一步怎么使力。

**moon 月相（4 张，一个周期）**
1. 新月：意图——这个月你想种下什么。
2. 上弦：行动——把它推起来要做什么。
3. 满月：觉察——这个月会被照亮的是什么。
4. 下弦：释放——该放下什么才走得动。

**horseshoe 马蹄形（7 张）**
1. 远期过去 → 2. 近期过去 → 3. 当前 → 4. 近期未来 → 5. 外部影响 → 6. 建议 → 7. 结果。

**celtic 凯尔特十字（10 张）**
1. 核心（现状中心）→ 2. 交叉（助力或阻力，压在核心上的那张）→ 3. 意识目标（你嘴上说要什么）→ 4. 根基（潜意识 / 真正的起点）→ 5. 近期过去 → 6. 近期未来 → 7. 自我（你的态度与姿态）→ 8. 环境（他人与处境）→ 9. 希望与恐惧（往往同一件事）→ 10. 结果（按现在的走法收在哪里）。

## 收牌时的口径

- 位置的顺序就是摆牌顺序，不许打乱；交叉牌（第 2 张）在解读里永远和核心牌成对读。
- 用户报牌时位置对不上张数（例如三张牌阵报了四张），先问清楚，别自行删掉一张。
