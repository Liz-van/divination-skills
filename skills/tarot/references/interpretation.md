# 解读方法、牌间关系与语言纪律

## 一、四维透镜（每张牌挑 1-2 个用，不要四个都套）

- **镜子**：这张牌在描述你现在的什么状态。
- **窗户**：你自己没看到的那一面（盲点、被压下去的情绪）。
- **门**：它可以变成什么动作。
- **锚**：它固定住了你哪个信念（常是「我不行」「这事只能这样」）。

逆位读法按牌位选一种，并说清选的是哪种：阻塞（能量卡住）、过度（过头了）、内化（向内走、还没对外）、延迟（时候没到）、反转（意思反过来）。

## 二、复数牌的牌间关系（两张以上必做）

1. **元素分布**：3 张以上同花色（含同元素）＝那股能量是主导；整副牌里缺席的花色＝被忽略的领域。火=行动、水=情感、风=思维、土=现实资源。
2. **大阿卡纳比例**：>50% 重大转折期；30-50% 命运与选择并存；<30% 日常选择主导——这时综合解读要强调主动权在用户手里。
3. **牌性（相邻两牌的元素互动）**：火风互助（想法推行动）；水土互助（情感落到现实）；火水蒸发（热情正好对上情绪，互相消耗）；风土僵化（想太多、动不了）；火土要落地（热情需要具体安排）；水风易情绪化思考（先安抚情绪再分析）。
4. **对位牌**：两张牌编号相加＝21（如愚者 0 + 世界 21、魔术师 1 + 审判 20）→ 镜像关系，一张在说「开始」，另一张在说「这开始的终点」。
5. **数字旅程**：同花色相邻数字＝推进；数字倒着走＝重启、补课；围绕 5＝正在经历危机；同数字不同花色＝同一阶段的两种呈现（例如圣杯五与宝剑五都是「损失与争执」，一个在心、一个在嘴上）。
6. **愚人之旅**：大阿卡纳 0-7 建身份，8-14 内在修正，15-21 阴影、崩塌、疗愈、整合；顺序出现＝在推进，倒序出现＝回头补课，同段落＝主题被强化。
7. **宫廷牌**：宫廷牌当「角色/姿态」读，另一张牌当「事件/处境」读——谁用什么姿态面对什么。
8. **相邻关系标签**：每对相邻牌标一个关系——`因果`（前一张导致后一张）、`对话`（两张在互相说事）、`递进`（同一件事在升级）、`转折`（方向变了）。标注可以给出来源（愚人之旅/数字旅程/牌性/对位牌/经典组合）。

牌间关系只写成立的那几条，不要写「不适用」「无关系」占篇幅。

## 三、综合叙事结构

按 **起点 → 张力 → 转折 → 出口 → 回响** 五段串成一条线：
- 起点：牌阵里最靠「过去/根部」的位置在说什么。
- 张力：冲突点在哪两张牌之间。
- 转折：哪张牌暗示了变化点。
- 出口：用户此刻能做的动作（必须具体）。
- 回响：这次解读要他带走的一句话。

## 四、禁用语与替换

| 不许说 | 改成 |
| --- | --- |
| 你注定会…… / 这是命 | 牌面显示的是一股倾向…… |
| 死神牌意味着死亡 | 死神的含义是一个阶段结束、新的阶段开始 |
| 高塔意味着灾难要来了 | 高塔说明不再有用的旧结构正在被清掉 |
| 你必须听牌的 | 牌提供了一个角度，决定权在你 |

**巴纳姆废话黑名单**（出现就重写）：注意沟通、保持平衡、相信直觉、顺其自然、放平心态、多关注自己、一切都会好起来、跟从内心。

## 五、特殊牌的处理

- **死神 XIII**：结束与转化，永远不读成死亡。
- **高塔 XVI**：拆旧结构，不制造恐慌，重点在拆完留下的空地。
- **恶魔 XV**：看清是什么绑住了你（成瘾、依赖、交换关系），引导自我观察，不描成道德审判。
- **宝剑十**：先承认确实很痛，再指出「触底了，路只剩往上」。
- **太阳/世界**：肯定成果时也要指出它对应的责任，不空夸。

## 六、边界

- 不问生日、不问塔罗牌以外的术数（八字、星座、 numerology 不是本 skill 的事）。
- 医疗、法律、投资买卖、要不要分手/辞职这类重大决定：只给反思框架，明确说「这不是专业建议，请找相应的人」。
- 用户对结果不安：告诉他塔罗里没有真正的坏牌；用户想重抽：说明第一次抽的牌信息量最大，可以换个问法再抽一次，不要反复抽到满意为止。
